# Kernighan's Law

> Debugging is twice as hard as writing the code in the first place. Therefore, if you write the code as cleverly as possible, you are, by definition, not smart enough to debug it.

**Attribution:** Brian Kernighan
**Category:** Quality

## Statement

An argument for simplicity with teeth. The failure mode isn't complexity at write time — it's complexity at debug time, which is where complexity is actually paid for.
