# Zawinski's Law

> Every program attempts to expand until it can read mail. Those programs which cannot so expand are replaced by ones which can.

**Attribution:** Jamie Zawinski
**Category:** Architecture

## Statement

A sardonic description of feature creep as evolutionary pressure. Software bloats toward universality not by design but by selection — users prefer the tool that can also do the adjacent thing.
