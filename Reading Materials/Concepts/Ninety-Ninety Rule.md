# Ninety-Ninety Rule

> The first 90 percent of the code accounts for the first 90 percent of the development time. The remaining 10 percent of the code accounts for the other 90 percent.

**Attribution:** Tom Cargill, Bell Labs
**Category:** Planning

## Statement

The tail of any project — polish, edge cases, integration, deployment — reliably costs as much as the "real work" that preceded it. Estimation that ignores the second 90% is estimation that is always wrong.
