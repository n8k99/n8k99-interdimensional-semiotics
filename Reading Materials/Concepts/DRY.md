# DRY

> Don't Repeat Yourself. Every piece of knowledge should have a single, unambiguous, authoritative representation.

**Attribution:** Hunt & Thomas, *The Pragmatic Programmer*, 1999
**Category:** Design

## Statement

About knowledge duplication, not code duplication — the distinction matters. Two functions with identical bodies that represent *different* ideas should not be unified. Two functions with different bodies that encode the *same* rule should.
