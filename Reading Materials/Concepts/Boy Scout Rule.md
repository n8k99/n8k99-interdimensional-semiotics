# Boy Scout Rule

> Always leave the code better than you found it.

**Attribution:** Robert C. Martin
**Category:** Quality

## Statement

Adapted from the scouting motto. A local norm that — if practiced — produces global improvement: every touched file trends toward cleanliness over time, without ever requiring a dedicated cleanup project.
