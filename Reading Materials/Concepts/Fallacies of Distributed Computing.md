# Fallacies of Distributed Computing

> Eight false assumptions distributed-system newcomers make: the network is reliable, latency is zero, bandwidth is infinite, the network is secure, topology doesn't change, there is one administrator, transport cost is zero, the network is homogeneous.

**Attribution:** L. Peter Deutsch et al., Sun Microsystems
**Category:** Architecture

## Statement

Each assumption is comfortable, each is wrong, and each eventually produces an outage when treated as true. The fallacies are not bugs to fix; they are biases to correct for in every design.
