# Gall's Law

> A complex system that works is invariably found to have evolved from a simple system that worked.

**Attribution:** John Gall, *Systemantics*, 1975
**Category:** Architecture

## Statement

You cannot design a complex working system from scratch. Every attempt produces something that fails to work, which must then be patched into working — at which point the original clean design is gone. Start simple; let complexity accrete from necessity.
