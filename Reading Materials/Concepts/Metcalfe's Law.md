# Metcalfe's Law

> The value of a network is proportional to the square of the number of connected users.

**Attribution:** Robert Metcalfe
**Category:** Scale

## Statement

Each new node can potentially connect to every existing node, so value scales with n². Explains winner-take-all dynamics in networked goods — and why network effects are nearly impossible to overcome once established.
