# Pesticide Paradox

> The same tests run repeatedly against the same code eventually stop finding new bugs.

**Attribution:** Boris Beizer, 1990
**Category:** Quality

## Statement

Tests harden the surface they cover but leave the uncovered surface unchanged. To continue finding bugs, the tests themselves must evolve — new inputs, new assertions, new attack surfaces.
